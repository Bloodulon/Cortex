# 🧠 Cortex — AI Quiz Bot
 
Telegram Mini App для обучения искусственному интеллекту через викторину и курсы.
 
---
 
## 📋 О проекте
 
**Cortex** — это образовательный Telegram бот с встроенным Mini App. Пользователи проходят викторины по темам AI/ML, зарабатывают XP, повышают уровень и соревнуются в глобальном рейтинге.
 
### Возможности
 
- 🎮 **Викторина** — вопросы трёх уровней сложности (Новичок / Средний / Эксперт)
- 📊 **Профиль** — XP, уровень, точность ответов, прогресс
- 🏆 **Лидерборд** — глобальный рейтинг игроков
- 📚 **Курсы** — каталог обучающих модулей по AI
- 📖 **Словарь** — персональный лексикон терминов

## 🏗️ Архитектура
 
```
Cortex/
├── bot/                    # Python бэкенд
│   ├── main.py             # Точка входа, запуск бота + API
│   ├── handlers.py         # Хэндлеры aiogram
│   ├── api.py              # FastAPI REST эндпоинты
│   ├── database.py         # Работа с PostgreSQL через asyncpg
│   ├── config.py           # Конфигурация
│   ├── questions.json      # Банк вопросов викторины
│   └── Dockerfile
├── frontend/               # Статичный Mini App
│   ├── index.html          # SPA с 5 страницами
│   ├── app.js              # Логика навигации, викторина, API
│   ├── style.css           # Стили
│   └── questions.json      # Вопросы для фронта
├── docker-compose.yml      # Локальная разработка
└── .env.example
```
 
### Стек
 
| Компонент | Технология |
|-----------|-----------|
| Бот | Python 3.12 + aiogram 3 |
| API | FastAPI + uvicorn |
| База данных | PostgreSQL + asyncpg |
| Фронтенд | Vanilla JS + Tailwind CSS |
| Хостинг бота | Railway |
| Хостинг фронта | Vercel |
